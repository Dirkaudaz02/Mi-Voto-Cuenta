# Mi Voto Cuenta

Aplicación web estática para registrar localmente tu historial electoral: año, cargo, candidato, partido, filtros y gráficos.

## Publicación

GitHub → Settings → Pages → Deploy from a branch → main → /(root).

## Privacidad

Los registros se guardan solo en localStorage del navegador. No se transmiten a GitHub. No están cifrados y los respaldos JSON tampoco. Evita dispositivos compartidos y guarda respaldos seguros.

## Limitaciones

Los datos se introducen manualmente. No se validan automáticamente contra SERVEL ni se consultan votaciones del Congreso.
